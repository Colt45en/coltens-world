Core handler pattern (mandatory):
1) Parse envelope: ToolCallEnvelopeSchema
2) Parse input: <Tool>InputSchema
3) Load dependencies deterministically (style spec, prefab spec, artifact refs)
4) Normalize order (sort lists if contract says order is non-meaningful)
5) Canonicalize payloads (stable JSON) + compute sha256 hashes
6) Write artifacts (content-addressed) if applicable
7) Append ledger event describing action + hashes proving it
8) Return output parsed by <Tool>OutputSchema

Canonical JSON rules (mandatory):
- Recursively sort object keys lexicographically
- Arrays:
  - Preserve order ONLY if contract declares it meaningful
  - Otherwise sort by stable keys defined by contract (prefab_id, node_id, source_id, etc.)
- Normalize line endings to \n
- UTF-8 encoding
- No implicit time in functional output

Hashing rules (mandatory):
- sha256(canonical_json(payload)) for all contract payload hashes
- sha256(raw_bytes) for binary assets (glb, png, etc.)
- Every output must include hashes that prove:
  - input_hash (or a set of input hashes)
  - style_hash when style rules are applied
  - artifact_hash when artifacts are produced
  - output_hash for any generated manifest/report/snapshot

Content-addressed identity rules (mandatory):
- prefab_id = "prefab:" + sha256(canonical_json(prefab_spec))
- style_id may be human (we.mesh.style.core) but style_hash is canonical truth
- snapshot_id = "worldsnap:" + sha256(canonical_json(snapshot_payload))
- artifact_id = "artifact:" + sha256(raw_bytes)

Ledger events (mandatory; stable field names):
Each meaningful action appends one event with:
- event_type (string, versioned where needed)
- occurred_at_utc (allowed; must NOT influence functional output)
- input_hashes (object)
- output_hashes (object)
- artifact_refs (array, stable-sorted)
- deterministic_context (engine version, contract version, tool id)

Quality gates (mandatory):

- Determinism tests:

- Stable ordering tests:
  - Shuffled input order (where order is non-meaningful) produces same output hash
- No placeholders in "done" logic:

Testing requirements (mandatory):
